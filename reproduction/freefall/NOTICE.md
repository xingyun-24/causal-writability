# Provenance

The raw-video training backbone is derived from the Seriality Gap codebase.
The `lib/diffsynth` Git submodule is pinned to DiffSynth-Studio commit
`afd101f3452c9ecae0c87b79adfa2e22d65ffdc3`.

This repository adds and retains only the final frozen dual-wall and
support-release benchmark code, manifests, evaluations, and GT-trajectory
interventions.  See `README.upstream.md` for the upstream project material.
